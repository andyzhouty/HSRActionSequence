# 真珠伤害与机制核对（4.6.54）

2026-11-07。依据 WSL 内 HSRVersionInspector 的 4.6.54 角色1503与光锥23055数据实现。现已接入独立欢愉队伤害试验；此试验生成自己的自动轴，不回放手动排轴页的锚点。

## 使用

在「银狼欢愉队伤害试验」导入 FreeSR 文件，通过「导入真珠位置」替换爻光、第三位或藿藿。真珠保留文件星魂、技能、光锥与遗器；不得与虚照占用相同位置。当前仍要求银狼及四名不同角色，不支持任意队伍。

可设置美学底本、E间隔、复制计入来源与敌方待抵挡伤害。底本默认优先虚照，否则银狼；E间隔默认3，即EAA。敌方待抵挡伤害默认0，不凭空消耗抵御池；非零值表示每人已结算其他减伤、尚未经过真珠抵御的受击伤害。

## 已核对并实现

- 防御力面板与普攻、强化普攻的防御倍率；防御转欢愉度、治疗加成及治疗理论值。
- 战技15好活计入、30常规能量；非攻击。好活常驻，上限50，升格75。队友回合开始获得5，每次真珠自身回合重置期间实际获取50点的额度。
- Q20好活、3次深度学习与底本；按欢愉人数拉条10%/15%/30%，四欢愉给予额外回合。2魂给其他欢愉队友拉条，临时奖励翻倍。
- 秘技20好活、2次深度学习；强化普攻消耗1次，回复30常规能量与1战技点。欢愉底本触发复制伤害；非欢愉底本不触发此复制分支。
- 欢愉底本下一次Q给真珠固定90能量，不吃充能效率。入场与真珠Q重新设置单个、不叠加的待触发标记；深度学习耗尽后标记仍保留。
- 欢愉技本身非攻击、没有自身直伤，给各队友下一次攻击追加对应属性欢愉伤害；按1/2/3/4欢愉使用10%/15%/20%/40%，4魂翻倍。重复施加采用刷新而非叠层，待实测核验。
- 1魂团队欢愉度、2魂团队增笑、6魂深度学习期间穿透及额外复制；效果抵抗可联动龙骨。
- 四欢愉额外回合临时好活与笑点在结束时清理，升格保留比例取决于虚照星魂。临时笑点已经带来的银狼隐藏分不会被反向删除。额外回合不消耗虚照境界持续回合，也不重置自然行动计时。
- 专锥防御力、欢愉技全体易伤、固定10回能与治疗；真珠风套Q自身拉条。

复制伤害借用底本的伤害面板，默认使用真珠自己的好活计入量；此点尚需实测，界面可切换使用底本好活。复制直伤计入真珠并记录借用对象；欢愉技追加伤害计入实际攻击者，团队增益不重新归属真珠。

## 原排轴机制修复

1. 真珠额外回合原先无论手动填写什么都执行A。现在尊重A/E输入，剔除该回合不允许的Q，且保留自然回合计时。
2. 虚照在真珠给予的额外回合中原先会减少境界剩余回合。现在保留行动相关处理，但不减少境界回合。

## 范围与待实测

伤害试验没有完整我方HP、减益及死亡模型，因此未模拟低血量减伤、1魂免死、驱散与有效治疗量。治疗记录为理论值；抵御池可通过输入受击伤害消耗。已有盲盒攻击分类和复制计入来源仍需游戏实测。

本次没有替换银狼生产概率模型：仍为资源动态C/8模型，玩家群讨论的联合候选尚未落地。不能把这里的结果当作候选概率模型或全局最优轴的结论。
