# 白厄伤害试验

这是随行动轴逐次回放的伤害试验，不是完整战斗模拟。页面下方可以导入账号级 FreeSR 文件；专用导入只选择白厄、布洛妮娅、花火、知更鸟四人的已装备遗器，不使用 `loadout` 中的其他方案，并替换当前队伍/轴。普通 JSON 导入与自动保存会保留伤害设置。

默认添加一名95级、200速的验证敌人，每50行动值行动一次，按对我方群攻处理；非变身白厄因此获得1点火种，境界内不获得。W强制敌方行动后，下次正常行动按50行动值重排。原FreeSR文件中的Boss、等级和祝福不自动代入这条验证轴。

白厄行迹1408101的参数为 `[3,1]`，原文开局引用 `#2`（1点）、退场引用 `#1`（3点）。开Q时至多3点溢出单独封存，境界内火种为0；退场后火种为 `3 + 封存溢出`。界面将火种与封存溢出分栏展示。

知更鸟E/Q不视为对白厄施放目标技能，不产生火种、白厄天赋暴伤或船长助力层数；增伤、协奏攻击力和1魂抗穿照常生效。示例轴让白厄第二次E保持自然行动时间；待首个50行动值群攻补足12火种后，单独插入Q，不覆盖E的行动值。白厄正常回合结束时到期的短期增益，不会因为稍后在敌方回合开Q而重新延长。

## 已实现

- 白厄0–2魂：普通 A/E、领域 A/W/E、最后一击、变身攻击、1魂暴伤、2魂物理穿透；毁伤按 `min(当前毁伤,4)` 消耗。`EA/EW` 仍使用排轴器现有的同一条行动记录，伤害层拆成两次结算，仅在前段消耗4毁伤时执行后段。
- A 默认6级；E/W、Q、天赋默认10级。辅助技能从配装读取并计入已实现的星魂增级，布洛妮娅3魂提升Q和天赋等级。
- 布洛妮娅E/Q与军势、花火E/Q/天赋及夜想曲、知更鸟E/Q和天赋，以及知更鸟1魂。花火 `enhanced_id=1` 时使用11306组：天赋/谜诡进入易伤区，强化夜想曲提供45%攻击和持有其E时10%抗穿。
- 验证配置中的光锥：23044 黎明恰如此燃烧、23003 但战斗还未结束、21018 舞！舞！舞！、23019 镜中故我；动态加成与常驻面板分开。
- 验证配置中的遗器：126船长、309竞技场、121司铎、110风套、308翁瓦克、102快枪手、123英豪。船长助力满2层后Q加48%攻击1回合；司铎仅单体E触发暴伤层，布洛妮娅群体Q不触发；竞技场按当次暴击率检查普攻/战技加成。船长文本参考[原始套装记录](https://gamevika.com/en/hsr/relic/126)。
- 防御、抗性、暴击、增伤、易伤、虚弱、减伤和独立乘区分开结算；未击破时另乘0.9。弹射按同质存活敌人等概率分布，结果为期望值。

## 计算边界

手动输入的白厄攻击、暴击、暴伤均为出战前面板，包含光锥基础属性、遗器和小行迹，不能重复填入战斗被动。三名辅助面板同理。专用FreeSR导入使用精确主副词条系数还原这些面板；导入后改动角色配置不会自动重新配装，应再次导入或手动更新面板。

只统计白厄伤害；不含知更鸟协奏附加伤害、辅助自身伤害、击破、敌人死亡/阶段机制、祝福或其他模式加成。布洛妮娅1魂随机战技点返还不自动模拟。缺火种、缺战技点、缺能量或不成立的2魂连动会在相应行提示，数值仍可作为假设施放下的伤害核对；优化搜索会拒绝这些轴。

## 能量

从FreeSR读取初始能量和能量上限；从当前遗器和光锥读取充能效率。默认普攻基础20、战技基础30、敌方群攻受击基础10，均乘充能效率；技能的额外回能单独结算。翁瓦克与5星满级能量绳合计24.4394%，受击一次回12.44394；布洛妮娅的23003光锥另提供10%。终结技先检查并扣除能量上限，再结算技能自带回能。

明确标为固定的回能直接加原数值，不乘效率。本次四人资料未将所用回能文案标注为固定，暂按普通回能处理；每个事件保留来源、基础值及固定/普通类型，供后续实测核对。回能包括入场秘技/镜中故我、技能、花火额外回能与知更鸟攻击回能。境界内离场的三名辅助不获得敌方群攻受击回能，白厄仍只使用火种与毁伤。

未导入能量字段的旧伤害设置，初始能量按50%、充能效率按100%回退；建议重新导入配装。

## 300行动值搜索

`tests/experiments/optimizePhainon.test.ts` 为手动启用的搜索入口。设置 `HSR_DAMAGE_SEARCH=1`、`HSR_FREESR_TEST_FILE`、`HSR_DAMAGE_REPORT_DIR`，运行该文件可保存候选最优轴；`HSR_SEARCH_BUDGET` 控制评估上限。`HSR_CRIT_RATE` / `HSR_CRIT_DAMAGE` 可覆盖导入的面板暴击，例如满暴试验用 `1` 与 `1.9`；覆盖值会写入导出的轴。`HSR_LOCKED_CASTS` 用 `角色@锚点@时序` 逗号分隔，锁定必须出现的终结技插入，其余位置照常搜索。搜索固定装备、敌人和300行动值，不覆盖自然行动值，不主动提前退场；比较A/E选择、终结技插入事件和多次开大，逐项校验能量、火种、SP与毁伤，并禁止领域内再次开Q及离场队友行动。

领域技能使用有限状态动态规划：对单默认A6/E10，在A/E/W/EA/EW中按毁伤搜索；对单结果以E/A为主，3目标及以上以E/W为主，截止前可消耗剩余不足4毁伤收尾。全轴使用确定性坐标搜索与扰动，不是全局最优证明。搜索所得JSON可以直接导入普通排轴页面。将 `HSR_SEARCH_VERIFY` 指向该JSON并运行 `tests/experiments/verifyPhainonSearch.test.ts`，可独立回放验证。

领域额外回合不消耗普通增益回合，光锥烈阳在白厄下一个正常回合开始移除。知更鸟协奏倒计时随队友行动一同冻结并在退场后继续；花火天赋采用刷新共享持续时间。W默认每个敌人立即行动一次，在全部强制行动后结算一次反击；多次行动或不同目标分配可通过保存数据的 `actionOverrides` 指定毁伤/反击层数/目标位置。

## 增益之间的结算口径（已按实战校正）

- **知更鸟协奏攻击力是实时值**，不是施放瞬间快照：鸭Q 即使晚于鸟Q 施加，也会立刻抬高协奏给全队的攻击力。协奏期间我方每次攻击后附加一次 72% 鸟攻击力、固定 100% 暴击/150% 暴伤的物理伤害，独立成行。
- **辅助暴伤二次转化**：花火E 的暴伤为「花火暴伤 × 24% + 45%」，鸭Q 为「布洛妮娅暴伤 × 16% + 20%」。计算时要先并入全队暴伤（知更鸟天赋 20%、鸭Q），再乘系数——花火E 因此会比只读面板高出约 16 点。
- **司铎**的到期值是该增益最后一个仍生效的白厄回合，清理必须在严格越过时才执行，否则两次单体E 之间层数会被提前清空、只能吃到 1 层。
- **最后一击不吃繁星竞技场**（只加普攻和战技），也不吃退场后才叠满的负世行迹 100% 攻击力；退场叠层在结算之后。
- **领域毁伤可以跨境界留存**：收尾留 2 点毁伤给下一次变身，比当回合打光更赚。搜索用 `ruinCarryValue` / 收尾上限 2 表达这一点；不是每个境界各自最优。
- **对单时 A 严格优于 W**（伤害更高、毁伤 +2），单体领域求解不再把 W 放进候选。

白厄1魂继续使用原有固定0.66速度系数；击杀提速无法预知，保留手动排轴方式。

## 增益持续回合的判定口径

扣减发生在技能目标的**回合开始时**，所以在目标回合开始之后才施加的增益不吃当回合那一层：「2回合」覆盖3次行动，「1回合」覆盖2次；在目标回合开始之前施加（例如他的上一个行动者结算完）则只覆盖持续回合数次。这是用户实战确认的口径，模拟按 `expires = 当前回合数 + 持续回合`、判定用 `expires >= 当前回合数` 实现。

因此「鸭Q 在鸭E 之后放」与「鸭Q 在白厄回合内、他E 之前放」不是同一件事：后者多覆盖一次白厄行动。两者在行动轴上的其余差别（舞舞舞与风套拉条时点、战技点结算顺序）同样会被模拟保留。

白厄在自身回合内先开大会直接变身并结束该回合，搜索仍只允许他的Q接在行动之后；辅助的Q两种时序都在搜索空间内。

## 数据与验证

技能、星魂、行迹、基础属性和四把光锥来自 HSRVersionInspector 4.6.54；遗器词条精确系数来自 ProjectHyacine 的 `shared/relic-affix-data.ts`。可在本项目根目录重新抽取版本数据：

```text
node scripts/extractDamageMetadata.mjs <HSRVersionInspector/data/4.6.54/zh>
node scripts/extractFreeSrSpeedMetadata.mjs <HSRVersionInspector/data/4.6.54/zh>
```

常规测试不依赖个人账号文件。要验证用户指定的实际配装，可设置 `HSR_FREESR_TEST_FILE` 为文件路径，并设置 `HSR_DAMAGE_REPORT_DIR` 为输出目录，再运行 `pnpm exec vitest run tests/integration/damage/freeSrPhainon.test.ts`。该测试读取当前文件，输出可导入的 `action-sequence-phainon-validation.json`、逐项结果 `damage-results.json` 和 `report.md`；不会将账号原始导出写入仓库。
