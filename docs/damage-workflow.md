# 伤害计算的网页操作流程

点击页面顶部「伤害计算」直达计算区，选择「欢愉队 · 自动模拟」或「白厄队 · 手动排轴」。两种计算保留独立页签，切换时保留已有配置与正在运行的搜索。

## 欢愉队

1. 选择完整队伍方案，点击「选择 FreeSR 文件并计算」。常用组合直接列出四人队名；其他组合在「自定义队友组合」中设置，虚照与真珠位置冲突时会阻止导入并指出原因。
2. 确认统计行动值、敌人等级、速度和数量。修改后自动更新伤害。
3. 先查看总伤、万/亿换算与角色贡献；需要优化时点击「开始自动搜轴」，比较均伤后应用候选。

网页导入默认保留文件星魂、光锥、遗器与强化状态，不再默认把用户配置改成旧验证配置。原验证配装在「配装来源」中仍可选择，替换规则会在导入前显示。原有脚本调用接口默认值保持兼容。只有已接入的光锥和80级角色能还原配装；遇到尚未支持的光锥时，界面提供切换验证配置或选择其他队伍的建议。藿藿目前仅支持强化版本，文件中的普通版本会明确拒绝，不静默开启强化。

导入结果会显示实际队伍与文件名；从旧JSON恢复的常用队伍也会同步队伍方案。导入失败不会覆盖现有配置。

技能循环、随机种子、阿哈基础速度、概率与机制选项放在「高级设置」；完整面板显示星魂、光锥名称与叠影、遗器套装名称。计算说明、逐轮资源与逐行动明细按需展开。主结果表示当前种子的单次模拟，搜轴列表按独立样本的平均总伤排序，两者明确区分。

## 白厄队

选择队伍、导入配装后生成示例轴并显示当前累计伤害。点击「返回上方调整行动轴」修改技能次序，伤害自动更新。面板与乘区收进高级设置，逐行动伤害默认折叠。当前支持范围与原有伤害计算口径保持一致。

## 验证

新增界面测试覆盖常用队伍选择、位置冲突、默认保留配装、未支持光锥的可操作提示、设置折叠、结果优先及页签键盘切换与状态保留。实际FreeSR文件核对原配装读取结果，并确认旧验证模式仍使用原有覆盖规则。浏览器实际完成配装恢复、伤害展示和后台搜轴。
