# 银狼Q消耗与资源审计（2026-11-07）

> 最新：银狼已改为[资源动态盲盒模型](silver-wolf-box-model.md)，默认a=C/8。下文等概率假设与相应数值均属历史。

用户撤回了35/55基准。之前基于该基准抑制两种Q产笑、主角欢愉技天赋触发的改动全部撤销。当前真实修正是：**银狼释放Q先消耗60隐藏分，再结算进入状态的行迹与光锥收益。** 三种盲盒仍各1/3；该轮当时暂不实现火花；现在已新增[火花分支](sparxie-trial.md)。

## 当前规则

- 主角Q恢复产5笑点，银狼普通ES直接15隐藏分，20笑点门槛奖励20；孤立合计40隐藏分。
- 一魂爻光Q恢复产5笑点，额外阿哈中的主角ES恢复天赋3笑点及固定10能量；银狼普通ES直接15、两个门槛合计40，孤立合计63隐藏分。
- 主角普通A/E和欢愉技都恢复攻击后天赋，固定10回能不吃充能效率。
- 银狼Q先扣60；示例158→98→行迹+20→专锥产笑+20→138。专锥没有就绪时不额外凭空加20。
- 扣除的60不计入无敌玩家的初始累计分或E2进度。循环记录entryHidden保留开Q前值，状态进度从扣除后的存量开始。
- Q消耗记录为独立隐藏分账本事件，与能量事件分开；300上限、退大保留去尾取整规则保留。
- 当前规则标记qCost60；旧存档中的user35_55、metadata4_6_54及缺省值都会迁移到当前规则，不会继续沿用旧错误计算。
