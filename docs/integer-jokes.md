# 笑点整数结算

依据用户实测口径，笑点每次变动后立即向下取整，不累计小数尾数。此规则对所有队伍默认生效，不设开关。

- 正向获得：先结算本次整数笑点，银狼天赋隐藏分与累计产笑使用实际获得值。例如回收5.9点，只得到5点；舍去的0.9不留给下一次回收。
- 百分比回收：虚照升格的爽点回收逐次取整。
- 临时笑点：真珠额外回合结束清理后，剩余共享笑点也向下取整。已经获得的隐藏分不会倒扣。
- 固定计入笑点与手动排轴：计入值、输入读取及虚照回收同步采用整数。

不改变能量、暴击期望、好活抵御池等其他数值的精度。旧JSON设置载入后会自动按当前算法重算，无需重新导入配装。

此前允许笑点小数的离线报告（包括23.62亿P95样本）属于旧规则结果，需要重算后才可与当前页面比较。本次用原有两队P95优先策略与原先1000个种子复核，保持配装、205速敌人、20%抗性和不计负债不变；详细本机结果在 `build/jokes-integer-audit/report.md`。本次复核没有重新搜索最优配速和策略。

回归覆盖每次笑点前值、后值和实际变化量均为整数；虚照小数回收不保留尾数；隐藏分转化只取实际整数收益。
