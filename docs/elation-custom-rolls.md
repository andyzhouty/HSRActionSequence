# 自定义暴伤衣配装：当前动态盲盒模型

当前默认a=C/8，详见[盲盒模型](silver-wolf-box-model.md)。此前等概率模型均伤59.69M、P90 66.31M为历史，不再作为当前值。

同配装、同策略、同100种子，现均伤54,729,252.32，P10–P90：53,913,111.27–55,478,384.62；原装备同组均伤42,668,619.49。

配装仍为用户指定副词条、银狼暴伤衣、爻光当她决定看见S1、主角伶人，其他主词条与内圈保留。藿藿生命按7×3.9%。银狼90分开Q、末50AV放宽、队友Q即时、藿藿和主角尽量E的策略未变，没有重新搜索最优门槛。

当前配置和明细在build/elation-custom-rolls/的preset.json、result.json、comparison.json。更新前所有文件在build/silverwolf-box-model/pre-resource-dependent/elation-custom-rolls/，其中原P90样例保持66.31M，可供历史复现对照。旧comparison-crit-rate-body等文件也只属于旧等概率模型，本轮未重算暴击衣。
