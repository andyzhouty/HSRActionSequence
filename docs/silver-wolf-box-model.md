# 银狼资源动态盲盒模型（2026-11-07）

> 最新已加入[虚照伤害与升格](star-aha-damage.md)，支持在导入时替换队友；旧文“虚照尚未实现”等范围说明已成为历史。

用户授权替换三种盲盒等概率模型，并要求低分阶段下降略慢且凹凸性不变。当前默认k=8，即a=C/8，替代最初的k=10。该模型是用户指定的定性近似，不是游戏概率实测。

## 概率

令s为开箱前当前战技点，S为当前战技点上限，x为当前隐藏分，C为隐藏分上限：

- 战技点箱P(A)=0.5×(1−s/S)。越缺战技点越容易触发。
- 笑点箱P(B)=0.5×[1−ln(1+8x/C)/ln9]。
- 真伤箱P(C)=1−P(A)−P(B)。这里的事件C与隐藏分上限C仅为用户原式同名，代码使用不同名称。

三者均非负且和为1。笑点箱在零分时50%、满分时0%；一阶导负、二阶导正，保持单调递减和向上凸。初始下降斜率的绝对值比a=C/10约低12.7%，而端点不变。

## 接入时序与配置

每次成功开箱都在奖励结算前抓取SP、SP上限、隐藏分和隐藏分上限；然后按此概率抽出奖励。消耗战技点触发的箱使用扣除战技点后的值。连开三箱时，前一个箱的返还/产笑已经影响后一个箱的概率，不会整次强化A锁定同一组权重。

火花专锥提高SP上限时使用真实上限8，没有硬编码为5。隐藏分上限默认300，通过hiddenScoreCap统一控制分数封顶和概率分母；界面可配置。虚照本人及其自动改变上限的机制尚未实现，不能声称已自动读取她的效果。未来接入应更新实际C，而不是改写概率公式。

配置新增boxProbabilityModel=resourceDependentV1、boxBeanCurveK=8、hiddenScoreCap=300。界面移除旧等权输入，显示曲线k和隐藏分上限。旧存档boxWeights会被丢弃并迁移为当前模型。k越小低分下降越慢；保持正数时凹凸性不变。

仅更改“开箱后是哪种奖励”的条件概率。消耗SP触发箱的成功概率及成功后×20%衰减机制未改；强化A内置箱数量未改。秘技固定怪味豆仍为固定结果，不参与随机概率统计，也不消耗这一次分支随机数。

boxContext记录抽奖前输入；boxProbabilities保持旧数组顺序[真伤、SP、笑点]。前端按事件名称明确显示概率，避免把A/B/C或数组顺序搞反。资源返还后行快照与抽奖前上下文可能不同，这是预期行为。
