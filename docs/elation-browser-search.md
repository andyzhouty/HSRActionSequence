# 网页后台自动搜轴

在排轴页下方「银狼欢愉队伤害试验」导入四人配装并启用计算，展开「后台自动搜轴」，选择精度与1～4个并行线程后点击开始。可查看阶段、已评估候选及模拟次数，随时取消。浏览器后台线程执行计算，不占用页面交互线程；切换标签页可继续，但浏览器节流可能降低速度。关闭或刷新页面不会保留运行中的搜索。

搜索固定启动时的队伍、配装、敌人、行动值上限、概率和机制设置，只优化行动策略：银狼Q门槛与末段放宽窗口、队友Q时机，以及当前队伍适用的虚照/真珠/藿藿/欢愉主E间隔、使者/底本目标、火花目标大奖数。不会通过改变待实测机制或装备取得更高伤害，也不搜索任意逐次行动的全部组合。

快速模式每候选8个种子粗筛、32个独立种子复核，最多2轮坐标搜索；深入模式32/128个种子，最多3轮并从两个起点搜索。各候选在同阶段使用相同种子，训练结果缓存去重，保留前5个候选、搜索所得策略和当前策略一起复核。排名依据独立复核的平均总伤；显示P10/P90采样分位数及相对当前策略的提升，不保证全局最优，也不代表游戏实测概率。

点击排名旁的「应用」只更新策略参数，完整明细继续使用界面的单个随机种子，因而单次伤害不会等于排名均值。应用后可正常保存JSON或导出计算明细。修改任何计算配置会停止旧搜索、清除旧结果，避免把旧配装结果套入新配置。取消和离开组件会终止所有工作线程。

实现位于 `src/damage/elationSearch.ts`（搜索）、`src/damage/elationSearchClient.ts`（线程池）、`src/damage/elationSearch.worker.ts`（后台计算）和 `src/components/ElationSearchPanel.tsx`。后台仍调用同一套完整模拟器，保持结算一致；只把伤害统计传回页面，不传输逐行日志。尚未拆分不生成日志的精简模拟模式。

当前入口针对银狼欢愉队。白厄现有伤害回放与离线搜轴不受影响，本次未增加白厄网页自动搜索。

验证：全量Node测试516通过、22跳过；界面110通过、3跳过，类型、架构、格式与构建检查通过。新增测试覆盖搜索收敛与去重、训练/复核隔离、真实模拟总伤一致、1/4线程一致、取消和错误清理、配置失效与候选应用。另以现有最高伤害轴配置完整跑通快速搜索，并在实际线程执行生产构建的Worker产物，核对消息与伤害返回。
